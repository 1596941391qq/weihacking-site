DEEP SEARCH LAB · PROJECT BRIEF

搜索给你链接。
研究需要证据链。

Deep Search Lab 是一套面向研究者、增长团队和独立开发者的搜索基础设施。它把公开网页、专业社区、非标论坛、社媒信号和 OSINT 补证放进同一条可追溯链路，回答的不只是“网上有什么”，还有“这件事为什么可信”。

WHY THIS EXISTS

普通搜索擅长回答流行问题。
真正困难的问题，证据往往散落在边缘。

一条产品失败经验可能只存在于论坛评论的第 14 页；一个开源项目的真实痛点藏在 GitHub Issue；一次市场判断需要同时核对新闻、历史页面、主体信息和社区反应。只搜网页标题，得到的是摘要，不是判断依据。

这个项目把“找到页面”和“拿到能验证的原始内容”拆开处理。每个结果尽量保留来源、抓取时间、使用的后端和置信度。无法获取、命中风控或需要登录时，也明确告诉你，而不是拿空结果冒充世界上没有答案。

HOW IT WORKS

四层系统，不靠单一搜索引擎押宝。

DISCOVER

发现层

Serper、Exa、Brave 计划通道、Hacker News、GitHub、Polymarket 与平台内搜索建立候选集。目标是广，不假装每个来源都同样可靠。

WEB / NEWS / CODE / MARKET / COMMUNITY
COLLECT

采集层

Apify 处理结构化平台；Firecrawl、Jina Reader 和 Obscura 读取公开页面；Chrome CDP 留给登录、验证码、强交互和人工接管。

API / ACTOR / HEADLESS / SESSION
VERIFY

补证层

DNS、WHOIS、历史快照、公开账号和跨源时间线用于核对主体与事件。OSINT 仅限公开信息，不执行侵入式扫描。

ENTITY / HISTORY / IDENTITY / TIMELINE
NORMALIZE

证据层

页面转为 Markdown 和统一证据对象，记录原始 URL、时间、采集方式与失败原因，供搜索 Demo、Agent 和后续研究编排复用。

MARKDOWN / TRACE / CONFIDENCE / CITATION

5-stage

网页转证据降级链：Serper → Firecrawl → Jina → Obscura → Chrome。

BHW ✓

Obscura 已真实产出论坛首页 Markdown；BBHF 的 Cloudflare 与 OneHack 的兼容问题仍明确保留。

TRACE

结果保留来源、时间与采集方式；后续将补齐查询级成本和完整引用覆盖率。

当前边界

这仍是公开 Demo，不是已经完成的万能调查产品。论坛登录态、完整增量索引、长任务研究编排和公开 SLA 尚在建设；涉及授权的动作不会自动越过审批点。

WHO IT IS FOR

给需要形成判断的人，不给只想多看十条链接的人。

研究者与分析师

快速搭建证据地图，找出来源冲突、未知项和需要继续追查的位置。

增长与 SEO 团队

从真实用户语言、论坛失败经验和竞品足迹中发现需求，不把搜索量当全部市场。

独立开发者

验证痛点、技术路线和早期用户语境，减少“大家应该会需要”的自我感动。

Agent 工程师

通过统一能力目录和路由器获得可降级、可追踪的搜索与采集后端。

PUBLIC ROADMAP

下一步不是再堆十个 Logo。

  1. 把 Demo 变成真搜索产品真实 API 状态、异步任务、来源筛选和证据导出。
  2. 建立论坛增量索引公开页由 Obscura 定时采集；登录态与高风控站由 Chrome 补位。
  3. 接入研究编排层让 Local Deep Research 负责拆题、多轮追查和引用报告，底层仍统一走 OMGgrow Router。
  4. 建立公开跑分比较召回、引用正确率、延迟、成本和失败率，而不是比较“支持多少引擎”。
